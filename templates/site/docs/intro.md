# User guides

Every guide here is a numbered walkthrough of one task, with a screenshot of the
real app at each step. The control you need to use is outlined in each picture.

## How to use these guides

- Work top to bottom — each step assumes you completed the one before it.
- The number badge in a screenshot matches the number of the step it belongs to.
- Anything in a <kbd>keyboard</kbd> style is a key to press.

## Guides

Pick a guide from the sidebar to get started.
